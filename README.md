## Installation & Use

Open the project folder with VS Code and execute the following command to install the dependency package:

```
flutter pub get
```

Using VS Code or Android Studio to Open this project, F5 or Ctrl + F5 to run the project, and then you can start developing and debugging.

## Release

Build appbundle or apk (for Android)
```
flutter build appbundle
flutter build apk
```

Build iOS (for iOS, using XCode upload)
```
flutter build ios
```
